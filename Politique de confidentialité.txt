## 4. Analyse

### Mixpanel

Nous utilisons Mixpanel, un service d’analyse produit, pour comprendre comment les utilisateurs interagissent avec Historical Wisdom et pour améliorer l’Application. Notre projet Mixpanel est configuré pour une **résidence des données dans l’UE** (les événements sont envoyés vers le point de terminaison de l’API UE de Mixpanel).

Les informations envoyées à Mixpanel peuvent inclure :

* un identifiant utilisateur aléatoire et spécifique à l’Application (`user_id`) ;
* les lancements de l’Application ;
* les événements d’intégration (onboarding) et les informations relatives aux étapes d’intégration (y compris un identifiant d’étape tel que `name`, `inspirations` ou `legal` — ceux-ci identifient quel écran d’intégration a été affiché, et non votre nom d’affichage) ;
* la source d’acquisition sélectionnée par l’utilisateur ;
* les affichages de l’écran d’achat (paywall) ;
* les tentatives d’achat et les résultats d’achat ;
* les taps de restauration ;
* les identifiants de produits pour les abonnements ;
* si l’intégration a été terminée ;
* si Premium est actuellement actif ;
* les libellés d’Application que nous attachons aux événements, notamment `app` (« Historical Wisdom ») et `platform` (« iOS ») ;
* les informations relatives à l’Application et à l’appareil fournies par le SDK Mixpanel, telles que la version du système d’exploitation, la version de l’Application, le modèle d’appareil, la taille de l’écran et les informations relatives au SDK/à la bibliothèque.

L’Application n’envoie pas à Mixpanel votre nom d’affichage, votre adresse e-mail, votre numéro de téléphone, vos citations enregistrées, votre historique de recherche, vos collections de citations sélectionnées, le contenu des notifications ni votre localisation.

Nous avons désactivé l’enrichissement géographique basé sur l’adresse IP dans notre configuration d’analyse Mixpanel. Nous n’utilisons pas intentionnellement l’analyse Mixpanel pour déterminer votre ville ou votre localisation précise.

Les événements automatiques Mixpanel sont désactivés. Nous n’envoyons que les événements personnalisés décrits dans la présente politique.

### Finalités de l’analyse

Nous utilisons l’analyse pour :

* comprendre comment les utilisateurs découvrent et utilisent l’Application ;
* mesurer l’achèvement de l’intégration ;
* comprendre l’interaction avec Premium et les écrans d’achat ;
* mesurer la conversion d’abonnement et l’activité de restauration ;
* identifier les aspects techniques ou produit à améliorer ;
* évaluer l’efficacité des sources d’acquisition sélectionnées par les utilisateurs.

Nous ne vendons pas les données d’analyse.

## 11. Suppression des données

Vous pouvez demander la suppression des données associées à votre utilisation de Historical Wisdom.

L’Application propose une fonction **Supprimer mes données** sous **Profil → Confidentialité**.

Lorsque vous utilisez cette fonction, l’Application capture uniquement les identifiants nécessaires pour identifier les enregistrements concernés :

* le `distinct_id` Mixpanel associé à l’installation ; et
* le `app_user_id` RevenueCat associé à l’installation.

Ces identifiants sont envoyés à notre service sécurisé de suppression uniquement pour traiter la demande de suppression.

### Suppression Mixpanel

Notre service de suppression soumet une demande de suppression à Mixpanel pour l’identité d’analyse spécifiée.

Cette demande couvre le profil Mixpanel associé et les événements d’analyse appartenant à cette identité.

Mixpanel peut nécessiter un délai supplémentaire pour achever la suppression des données d’événements historiques. Le cas échéant, la suppression peut prendre jusqu’à environ 30 jours.

L’Application réinitialise également son identité Mixpanel locale afin que l’identifiant supprimé ne soit plus utilisé pour les analyses ultérieures.

### Suppression RevenueCat

Notre service de suppression demande la suppression de l’enregistrement client RevenueCat spécifié.

Cela supprime les informations client RevenueCat associées à cet identifiant, y compris les attributs pertinents et l’historique d’achats/abonnements stocké par RevenueCat.

L’API actuelle de RevenueCat prend en charge la suppression des clients et peut mettre la suppression en file d’attente pour traitement.

### Réinitialisation de l’identifiant local

Une fois les demandes de suppression soumises avec succès, l’Application supprime l’identifiant d’analyse précédent du stockage local et génère un nouvel identifiant spécifique à l’Application si vous continuez à utiliser l’Application.

Cela empêche que les événements d’analyse ultérieurs soient associés à l’identité d’analyse précédente.

### Ce que la suppression ne fait pas

La suppression de vos données d’analyse Historical Wisdom et de vos données client RevenueCat **ne** résilie **pas** un abonnement Apple actif.

Apple continue de gérer un abonnement actif de manière indépendante. La suppression de l’Application ou l’utilisation de **Supprimer mes données** ne suffit pas, à elle seule, à interrompre le renouvellement de l’abonnement.

Vous devez résilier un abonnement actif via le système de gestion des abonnements d’Apple.

Si vous continuez à utiliser Historical Wisdom alors qu’un abonnement Apple reste actif, votre droit d’accès Premium peut être restauré et un nouvel enregistrement client RevenueCat peut être créé pour le nouvel identifiant de l’Application. RevenueCat confirme que la suppression d’un client RevenueCat ne résilie pas un abonnement Apple.

Les enregistrements de transaction et les archives juridiques indépendants d’Apple peuvent également être conservés par Apple conformément aux politiques et obligations légales d’Apple.
